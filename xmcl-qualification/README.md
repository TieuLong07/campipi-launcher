# xmcl-qualification

XMCL (`@xmcl/core`) qualification work — phase 0 spike for the
campipi-launcher project.

This folder documents the clean-engine experiment that proved the launch
path (Forge 1.20.1 install → vanilla Minecraft → mods) works end-to-end
without the TLauncher-style layout.

See [`../docs/adr/`](./adr) (when added) for the architectural decision
that led to switching to the TLauncher-compatible shared-instance model
used by the main `phase1-app/` launcher.
